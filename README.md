# ORBITE

Tâches, agenda et projets. Remplace l'espace Notion « ORBITE ».

- Interface : HTML/JS statique (aucune compilation), installable sur téléphone (PWA).
- Données : Supabase, projet `orbite` (ca-central-1), protégées par RLS.
  Seul le compte propriétaire (le premier qui s'est connecté) peut lire ou écrire.
- Hébergement : GitHub Pages (branche `main`, dossier racine).

## Contenu

| Vue | Rôle |
| --- | --- |
| Accueil | Compteurs, en cours, backlog, 7 prochains jours, blocages, projets en mouvement, fiches à compléter |
| Agenda | Événements, tâches planifiées et échéances, jour par jour |
| Projets | Avancement, santé, résultat attendu et actions de chaque projet |
| Actions | Recherche et filtres sur tout (statut, type, projet) |
| Repères | Domaines de vie, personnes et organisations |

Capture rapide : bouton orange, ou touche **N** sur ordinateur.

## Tables

`actions`, `projets`, `domaines`, `personnes`, `proprietaire`, vue `projets_suivi`.

(colonne `notion_id` pour la traçabilité).
